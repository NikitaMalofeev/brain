# 📝 CHANGELOG - Brain Programming

Хронологический список изменений и обновлений проекта.


## [1.3.0] - 2025-01-06 📚 ДОПОЛНИТЕЛЬНЫЕ МАТЕРИАЛЫ

### ✨ Добавлено
- **MaterialsManager компонент** - полное управление дополнительными материалами
  - Список материалов с фильтрами по типу (video/audio)
  - Инлайн-редактирование названий, описаний и порядка с debounce
  - Модальные окна создания/редактирования материалов
  - Загрузка обложек материалов через CloudFlare R2 в папку `images/`

- **DraggableMaterialBlockRow** - Drag & Drop для блоков материалов
  - Перетаскивание блоков для изменения порядка
  - Визуальная обратная связь при перетаскивании
  - Автоматическое сохранение нового порядка
  - Плавные анимации переходов

- **Поддержка m4a аудио файлов** - расширенная поддержка аудио форматов
  - Добавление m4a в acceptedTypes FileUploader
  - Корректное отображение m4a файлов в превью
  - Поддержка воспроизведения m4a в браузере

- **JavaScript валидация** - проверка данных перед сохранением
  - Валидация обязательных полей материалов и блоков
  - Проверка корректности URL для видео блоков
  - Валидация типов файлов при загрузке

- **Альтернативный ввод URL** - возможность ручного ввода URL файлов
  - Переключение между загрузкой файла и URL вводом
  - Валидация введенных URL
  - Интеграция с FileUploader компонентом

### 🎯 Улучшено
- **Унифицированный интерфейс** - одинаковая логика для уроков и материалов
  - Консистентные CSS стили с остальной админкой
  - Переиспользование FileUploader компонента
  - Единые модальные окна и формы

- **CloudFlare R2 интеграция** - расширенная файловая система
  - Папки организованы по типам: `images/`, `audio/`, `documents/`
  - Поддержка всех типов файлов: аудио (включая m4a), изображения, PDF
  - Генерация уникальных имен файлов

### 🗄️ База данных
- **Таблицы материалов** - `materials` и `material_blocks`
  - Поля для типов, порядка, обложек и контента
  - Связи между материалами и их блоками
  - Поддержка различных типов контента: text, video, audio, image, pdf

### 📝 Документация
- **Обновлена документация админки:**
  - `admin_design_specification.md` - новые компоненты и CSS стили
  - `admin_materials_markup.md` - полная реализация со статистикой
  - `admin_cloudflare_r2_integration.md` - поддержка материалов и m4a
  - `admin_user_flow.md` - секция 4.A полностью реализована
  - `TASK.md` - очищены завершённые задачи, обновлена готовность

### 🎨 CSS стили
- **Новые классы для материалов:**
  - `.draggable-block-row` - стили для Drag & Drop блоков
  - `.material-type-filter` - фильтры типов материалов  
  - `.material-cover-preview` - превью обложек материалов
  - Интеграция с существующей системой glass-эффектов

## [1.2.0] - 2025-06-04 🎨 СИСТЕМА ОБЛОЖЕК

### ✨ Добавлено
- **Система обложек уроков** - полная интеграция с CloudFlare R2
  - FileUploader компонент в админке для загрузки JPG, PNG, WEBP
  - Поле `lessons.cover_image_path` в базе данных
  - Превью обложек в таблице уроков админки (40x40px)
  - Модальные окна для редактирования обложек
  - Фолбэк на дефолтные обложки при ошибках загрузки

- **Система обложек ступеней** - аналогичная интеграция
  - Поле `course_stages.cover_image_path` в базе данных  
  - Интеграция FileUploader в StagesManager
  - Превью и управление обложками ступеней

- **Функция удаления файлов** - `deleteFileFromR2` для очистки неиспользуемых файлов

### 🎯 Улучшено
- **Соответствие дизайну Figma** - приведены размеры обложек к стандарту
  - LessonPage: высота 193px, скругления только снизу
  - LessonCard: высота 193px, скругления только сверху
  - Соотношение сторон 343:193px (≈1.78:1)

- **Диагностика загрузки изображений** - логи в консоли для отладки
- **buildImageUrl функция** - корректное формирование URL из CloudFlare R2

## [1.1.0] - 2025-01-30 ⚡ ВРЕМЕННОЕ УПРАВЛЕНИЕ

### ✨ Добавлено
- **Поля времени для уроков:**
  - `open_at` - точное время открытия урока
  - `deadline_at` - дедлайн сдачи задания
  - Автоматический расчет: open_at + 2 дня = deadline_at

- **Система дедлайнов:**
  - Статусы "Дедлайн сегодня", "Дедлайн завтра", "Опоздание"
  - Отображение на карточках уроков для пользователей
  - Динамическое определение опоздания в админке

### 🎯 Улучшено
- **Логика времени в админке:**
  - `getDefaultOpenTime()` - завтра в 9:00 по умолчанию
  - `calculateDeadline()` - автоматический расчет дедлайна
  - UTC ↔ локальное время конвертация
