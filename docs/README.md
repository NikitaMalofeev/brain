# Реализованный функционал приложения "Brain Programming"

Приложение представляет собой современную платформу для онлайн-обучения с полным циклом создания и прохождения курсов, построенную на базе новой дизайн-системы.

## 🎨 Дизайн-система и UI/UX

### Новая дизайн-система (обновлено 29.01.2025)
- **Современные градиенты**: Основной фиолетовый (#E1C1F4 → #B862EA), голубой (#8DC5F1 → #63ABE6)
- **Glass-эффекты**: backdrop-filter с blur(20px-32px) для современного look & feel
- **Компонентная система**: Единые стандарты для карточек, кнопок, форм и навигации
- **Скругления**: От 12px до 32px для создания дружелюбного интерфейса
- **Типографика**: Nunito как основной шрифт с четкой иерархией размеров

### Figma интеграция
- **Полная синхронизация**: 9 основных экранов с Figma ID (682-4667 → 682-4675)
- **Техническая документация**: YAML спецификации всех компонентов
- **Система иконок**: Navigation, Communication, Library, User семейства
- **Состояния компонентов**: Hover, Active, Disabled для всех интерактивных элементов

### Компонентная архитектура
```yaml
# Основные компоненты дизайна:
cards:
  - defaultCard: белый фон, тонкая обводка, 24px радиус
  - gradientCard: фиолетовый/голубой градиент
  - glassCard: полупрозрачность + backdrop blur

buttons:
  - primaryButton: gradient-primary фон
  - secondaryButton: gradient-secondary фон
  - ghostButton: glass-эффект с прозрачностью

navigation:
  - tabBar: 60px высота, градиентные активные состояния
  - navigationBar: прозрачный, 44px высота
```

### Адаптивность и доступность
- **Mobile-first**: Основной фокус на 375px ширину (iPhone/Telegram)
- **Touch-friendly**: Минимум 44px для всех интерактивных элементов
- **WCAG 2.1 AA**: Соответствие стандартам контрастности
- **Анимации**: respects prefers-reduced-motion

## 📚 Пользовательский функционал

### Библиотека курсов
- **Отображение ступеней курса**: Пользователь видит карточки доступных и заблокированных ступеней курса
- **Данные из Supabase**: Информация о ступенях (название, статус блокировки, порядок) загружается из базы данных
- **Визуальное разделение**: Карточки отображаются в два столбца с адаптивным дизайном
- **Нумерация ступеней**: Под каждой карточкой выводится порядковый номер ("1 ступень", "2 ступень")
- **Статус блокировки**: Заблокированные ступени отображаются с иконкой замка
- **Навигация к ступени**: Реализован переход к детальному просмотру ступени

### Просмотр ступени
- **Список уроков ступени**: Отображение всех уроков с обложками и статусами
- **Карточки уроков**: Вертикальный макет с обложкой (171px), названием и статусом
- **Индикация заданий**: Уроки с домашними заданиями помечены специально
- **Прогресс пользователя**: Отображение завершенных/незавершенных уроков
- **Последовательная разблокировка**: Следующий урок открывается после завершения предыдущего

### Просмотр урока
- **Мультимедийный контент**: Поддержка видео (Kinescope), аудио, текста, изображений
- **Видеоплеер**: Интеграция с Kinescope с кастомным дизайном
- **Аудиоплеер**: Собственный плеер с современным дизайном (glass-эффекты, waveform визуализация)
- **Блочная архитектура**: Урок состоит из блоков разных типов (video, audio, text, image)
- **Завершение урока**: Кнопка "Урок пройден" для уроков без заданий

### Система домашних заданий
- **Fixed форма сдачи**: Форма ввода внизу экрана (как в мессенджерах)
- **Загрузка файлов**: Интеграция с CloudFlare R2 для прикрепления файлов
- **Автоматический прогресс**: Создание записи lesson_progress при сдаче задания
- **Отображение сданного ДЗ**: Показ текста задания и прикрепленных файлов
- **Навигация**: Возврат к списку уроков после сдачи

## 🛠️ Административный функционал

### Система ролей
- **Три роли**: admin, curator, user с разными уровнями доступа
- **Проверка прав**: Только admin/curator могут редактировать контент
- **Безопасность**: RLS политики в Supabase для контроля доступа

### Проверка домашних заданий (✅ Полностью реализовано)
- **SubmissionsManager**: Список всех сдач с фильтрами и сортировкой
- **SubmissionDetail**: Детальный просмотр с формой проверки
- **Изменение решений**: Кураторы могут корректировать свои решения, админы - любые
- **Корректировка баллов**: Возможность изменить количество баллов для принятых заданий
- **Система статусов**: submitted → pending_review → approved/rejected
- **Автоматический пересчет**: Баллы пользователя обновляются автоматически

### Модульная архитектура админки (✅ Новое!)
- **Рефакторинг AdminPage.tsx**: Сокращен с 2030+ до ~1500 строк
- **Компонентная структура**: Создана папка `src/pages/AdminPage/components/`
- **Модульные компоненты**:
  - `DraggableBlockRow.tsx` - перетаскиваемая строка блока (83 строки)
  - `DraggableLessonRow.tsx` - перетаскиваемая строка урока (172 строки)
  - `LessonsManager.tsx` - полный менеджер уроков с drag & drop (276 строк)
- **Принцип модульности**: Каждый компонент < 300 строк для лучшей поддержки

### Drag & Drop функциональность (✅ Новое!)
- **Технология**: Atlassian Pragmatic Drag and Drop - высокопроизводительная библиотека
- **Drag & Drop для блоков**:
  - Визуальные эффекты (голубая подсветка при перетаскивании)
  - Автоматический пересчет `order_num` для всех затронутых блоков
  - Интеграция с существующим BlocksManager
- **Drag & Drop для уроков**:
  - Визуальные эффекты (фиолетовая подсветка при перетаскивании)
  - Отключение drag в режиме редактирования урока
  - Автоматический пересчет порядка всех уроков в ступени
  - Функция `handleLessonReorder` с оптимизированной логикой

### Управление курсами
- **CRUD операции**: Создание, редактирование, удаление курсов
- **Модальные формы**: Удобные формы для редактирования
- **Валидация**: Проверка обязательных полей

### Управление ступенями
- **Иерархическая структура**: Ступени привязаны к курсам
- **Порядок отображения**: Настройка последовательности ступеней
- **Ручная разблокировка**: Поле is_unlocked для управления доступом
- **Breadcrumb навигация**: Отслеживание текущего местоположения

### Управление уроками
- **Привязка к ступеням**: Уроки организованы по ступеням
- **Обложки уроков**: Загрузка изображений через CloudFlare R2
- **Настройка заданий**: Флаг has_assignment для уроков с ДЗ
- **Drag & Drop**: Перетаскивание для изменения порядка уроков

### Управление блоков урока
- **Типы блоков**: video, audio, text, image с разными настройками
- **Kinescope интеграция**: Прямая поддержка video_id для видео
- **Файловый менеджер**: Загрузка аудио, изображений, документов
- **Drag & Drop**: Перетаскивание для изменения порядка блоков
- **Предпросмотр**: Возможность протестировать блоки
