# Функционал выбора ступени в "Библиотеке"

На данный момент в приложении реализован следующий функционал, связанный с выбором ступени обучения на экране "Библиотека":

- **Отображение списка ступеней**: Пользователь видит карточки доступных и заблокированных ступеней курса.
- **Данные из Supabase**: Информация о ступенях (название, статус блокировки, порядок) загружается из базы данных Supabase.
- **Визуальное разделение**: Карточки отображаются в два столбца.
- **Нумерация ступеней**: Под каждой карточкой выводится ее порядковый номер (например, "1 ступень", "2 ступень").
- **Статус блокировки**: Заблокированные ступени отображаются с иконкой замка.
- **Основа для навигации**: Подготовлен обработчик клика по карточке ступени, который в будущем будет осуществлять переход к содержимому ступени.
