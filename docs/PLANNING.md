# PLANNING

## Архитектура
- Проект построен на React + TypeScript с использованием Vite.
- Данные хранятся и запрашиваются через Supabase.
- Поддержка Telegram Web App через @telegram-apps/sdk-react.

## Цели
- Поддерживать единый стиль компонентов согласно Figma.
- Обеспечивать адаптивность и корректное выравнивание карточек.
- Сохранять модульность и читаемость кода (SOLID, DRY, KISS).

## Стиль и ограничения
- Следовать стандартизированному форматированию Prettier/ESLint.
- Компоненты разбивать по функциональным модулям.
- Максимум 500 строк на файл. При необходимости — рефакторить.
- Все изменения документировать в TASK.md по ходу работы.

## 3. Технологический стек

- **Frontend:** React, TypeScript, Vite
- **Backend:** Supabase (PostgreSQL, Auth, Functions)
- **UI/UX:** Figma
- **Deployment:** Vercel (Frontend), Railway (если потребуется Backend)

## 4. Стиль кода и стандарты

- **TypeScript/React:** Стандарты сообщества, Prettier, ESLint.
- **Общие принципы:** SOLID, DRY, KISS.
- **Комментарии:** На русском языке, для нетривиальных участков кода.
- **Размер файлов:** Лимит ~500 строк.
