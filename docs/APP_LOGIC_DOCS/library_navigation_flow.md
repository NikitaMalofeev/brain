# 📚 Library Navigation Flow

Этот флоу описывает поведение экрана "Библиотека", где пользователь выбирает ступень (этап) обучения.

---

## 🧭 Что видит пользователь

Экран построен по блоку Библиотека из Figma.  
Он содержит:

- Название экрана: **«Библиотека»**
- Приветственный текст (опционально): например, «Выберите этап, с которого хотите продолжить»
- Список карточек ступеней:
  - Название этапа (например, «1. Предобучение», «2. Основной блок»)
  - Прогресс по этапу (например, «2/5 материалов пройдено»)
  - Статус доступа: 🔓 открыт / 🔒 закрыт

---

## 📦 Какие данные подгружаются

Из Supabase по текущему пользователю вытягиваются:

- его активное участие в курсе (`user_course_enrollments`)
- список этапов (`course_stages`)
- статус открытия каждого этапа
- прогресс (кол-во просмотренных материалов и сданных заданий)

---

## 🔄 Как работает

1. **При открытии библиотеки:**
   - фронт делает запрос на список всех `course_stages`, отсортированных по `order`
   - для каждого этапа определяется, открыт он или нет:
     - если `unlock_condition_type = days_after_start` → сравниваем с `enrollment_date`
     - если `unlock_condition_type = previous_stage_completed` → проверяем, завершён ли прошлый

2. **Формируется список карточек:**
   - Открытые: можно нажать, переход к экрану этапа
   - Закрытые: замочек, кнопка неактивна

3. **При клике на открытую ступень:**
   - переход к `stage_content_flow` с `stage_id`

---

## 💡 UX-детали

- Открытая карточка — кликабельная, с визуальным эффектом нажатия
- Закрытая карточка — полупрозрачная, с иконкой замка
- Если этап открыт, но пользователь ещё ничего не проходил — показывается «0% завершено»

### 🏷️ Плашки статуса уроков

Каждая карточка урока отображает статусные плашки с приоритетом отображения:

1. **"Откроется завтра"** (высший приоритет)
   - Показывается для уроков с `open_at` = завтра (с 00:00 до 23:59)
   - Стиль: голубой градиент `bg-[linear-gradient(135deg,_rgba(141,197,241)_-48.61%,_#63ABE6_105.56%)]`
   - Цвет текста: белый
   - Логика определения: `getLessonTimeStatus(lesson)` в `LessonCard.tsx`

2. **"Завершено"** (если урок пройден)
   - Показывается для уроков с `is_completed = true`
   - Стиль: зеленый фон `bg-green-500`

3. **"Не начато"** (если урок разблокирован)
   - Показывается для доступных неначатых уроков
   - Стиль: голубой градиент (как "День N")

4. **"Заблокировано"** (если урок недоступен)
   - Показывается для заблокированных уроков
   - Стиль: серый фон `bg-gray-500`

**Техническая реализация:**
- Функция `getLessonTimeStatus()` проверяет время открытия урока
- Сравнение с завтрашним днем: от 00:00 до 23:59
- Обновлен тип `LessonData` с полем `open_at` в `useStageDetails.ts`
