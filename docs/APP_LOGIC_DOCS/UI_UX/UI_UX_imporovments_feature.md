# UX Улучшения для Telegram Mini App

Этот документ содержит список предложений по улучшению пользовательского опыта (UX) нашего приложения, разработанного как Telegram Mini App, с фокусом на мобильные устройства.

---

### 📋 Список UX-улучшений:

1. **Ripple Effect (Эффект "волны") — Детализация и План**
    *   **Суть:** Использование "волнового" эффекта при нажатии на интерактивные элементы. Это дает пользователю мгновенное визуальное подтверждение его действия, делая интерфейс более "живым", отзывчивым и тактильно приятным, особенно на мобильных устройствах.
    *   **Технический план реализации:**
        1.  **CSS-часть:**
            *   Для всех кнопок и кликабельных элементов, которые получат эффект, необходимо задать `position: relative;` и `overflow: hidden;`. Это "запрет" волну внутри элемента.
            *   Стили для самой волны (которая будет `<span>` элементом):
                *   `position: absolute;`
                *   `border-radius: 50%;` (чтобы была круглой)
                *   `transform: scale(0);` (изначально невидима)
                *   `animation: ripple 600ms linear;`
            *   Ключевые кадры для анимации `@keyframes ripple`:
                *   `to { transform: scale(4); opacity: 0; }` (увеличивается и исчезает)
        2.  **JavaScript-часть (создать хелпер-функцию):**
            *   Создать функцию, которая принимает `event` (событие клика или касания).
            *   **Кросс-платформенность:** Функция должна обрабатывать как `click` (для мыши), так и `touchstart` (для мобильных). Координаты нужно брать соответственно из `event.clientX/Y` или `event.touches[0].clientX/Y`.
            *   **Логика:**
                *   В момент события создать `<span>` элемент.
                *   Рассчитать его позицию. **Важно:** использовать `button.getBoundingClientRect()` для точного определения координат элемента на экране.
                *   Добавить `<span>` внутрь нажатого элемента.
                *   **Очистка:** Повесить на `<span>` обработчик события `animationend`, который будет удалять этот `<span>` из DOM после завершения анимации.
    *   ---
    *   **Централизованный План Реализации (React + Tailwind):**
        *   **Подход:** Мы создадим единый компонент-обертку `<Ripple>`, который инкапсулирует всю JS-логику. Стили для этого компонента будут централизованно управляться через Tailwind CSS для полной интеграции в дизайн-систему проекта.
        *   **Шаг 1: Стилизация через Tailwind.**
            *   Создать файл `src/components/ui/Ripple/Ripple.css`.
            *   В этом файле описать стили для "волны" (`.ripple-effect`) и контейнера (`.ripple-surface`) с использованием директив `@apply`. Это позволит использовать переменные (цвета, длительность анимации) из `tailwind.config.js`.
                ```css
                /* Пример для Ripple.css */
                .ripple-surface { @apply relative overflow-hidden; }
                .ripple-effect { @apply absolute rounded-full block bg-white/70; ... }
                ```
        *   **Шаг 2: Компонент `Ripple.tsx`.**
            *   Создать сам компонент в `src/components/ui/Ripple/Ripple.tsx`.
            *   Он будет импортировать `Ripple.css`.
            *   Компонент будет принимать `children` и оборачивать их в `div`, которому будет присвоен класс `ripple-surface`.
            *   Внутри JS-логики, при создании `<span>` для "волны", ему будет присваиваться класс `ripple-effect`.
        *   **Шаг 3: Пример использования.**
            ```jsx
            import { Ripple } from '@/components/ui/Ripple/Ripple';
            import { Button } from '@/components/ui/Button';

            // Просто оборачиваем любой интерактивный компонент
            <Ripple>
              <Button>Кнопка с красивым эффектом</Button>
            </Ripple>
            ```
    *   ---
    *   **План внедрения по страницам:**
        *   **`MainPage` (`/`) и `CommonPage` (`/library`):**
            *   **Элементы:** Карточки-ссылки на разделы (Библиотека, Профиль, Чаты, Помощь).
            *   **Действие:** Добавить ripple на всю поверхность карточек, чтобы усилить ощущение кликабельности.
        *   **`StagePage` (`/library/stage/:id`):**
            *   **Элементы:** Карточки уроков в списке.
            *   **Действие:** Применить ripple к каждой карточке урока.
        *   **`LessonPage` (`/library/lesson/:id`):**
            *   **Элементы:** Кнопка "Сдать ДЗ", кнопки внутри плеера (пауза/плей), кнопка "Следующий урок".
            *   **Действие:** Добавить ripple ко всем основным кнопкам действия.
        *   **`ProfilePage` (`/profile`) и `UserPage` (`/profile2`):**
            *   **Элементы:** Кнопки "Редактировать", "Выйти", иконки-ссылки.
            *   **Действие:** Применить ripple ко всем интерактивным элементам.
        *   **`Chats` (`/chats`):**
            *   **Элементы:** Элементы списка, ведущие в Telegram-чаты.
            *   **Действие:** Добавить ripple на каждый элемент списка.
        *   **`FaqPage` (`/faq`):**
            *   **Элементы:** Заголовки вопросов в аккордеоне.
            *   **Действие:** Добавить ripple на область заголовка, который раскрывает ответ.
        *   **`HelpPage` (`/help`):**
            *   **Элементы:** Кнопка "Написать в поддержку".
            *   **Действие:** Добавить ripple на кнопку.

2.  **Тактильный отклик (Haptic Feedback) — Детализация.**
    *   **Суть:** Использование встроенного в Telegram API виброотклика для усиления пользовательского опыта. Дает физическое подтверждение действий, делая интерфейс более отзывчивым и интуитивным.
    *   **Действия по реализации:** Интегрировать `Telegram.WebApp.HapticFeedback` для следующих сценариев:
        *   **Легкий отклик (`impactOccurred('light')`):**
            *   Нажатие на основные кнопки (кроме "опасных" типа удаления).
            *   Переключение табов в навигации.
            *   Активация/деактивация переключателей (checkbox, toggle).
            *   Выбор элемента в выпадающем списке.
        *   **Средний отклик (`impactOccurred('medium')`):**
            *   Успешная сдача домашнего задания.
            *   Разблокировка нового урока или ступени.
            *   Завершение важного действия (например, сохранение изменений в профиле).
        *   **Сильный отклик (`impactOccurred('heavy')`):**
            *   Использовать с осторожностью. Подходит для финального, самого важного действия в сценарии, например, завершение всего курса.
        *   **Системные уведомления:**
            *   **Успех (`notificationOccurred('success')`):** Принятие ДЗ куратором, получение достижения.
            *   **Ошибка (`notificationOccurred('error')`):** Ошибка отправки формы, потеря интернет-соединения, неудачная загрузка файла.
            *   **Предупреждение (`notificationOccurred('warning')`):** Потеря "жизни", уведомление о приближающемся дедлайне.
            *   **Изменение выбора (`selectionChanged()`):**
            *   При скролле карусели с карточками.
            *   При использовании слайдера (например, для настройки громкости).

3.  **Интро экран (Splash Screen).**
    *   **Суть:** Показывать интро экран при запуске приложения и отображать до тех пор, пока не загрузится весь основной контент
    *   **Действие:** Добавить интро экран и отображать его до тех пор, пока не загрузится весь основной контент

4.  **Плавные переходы и анимации.**
    *   **Суть:** Использовать плавные анимации для переходов между экранами, изменения состояний элементов (нажатия, загрузка) и появления контента. Это делает интерфейс "живым" и профессиональным.
    *   **Действие:** Добавить анимации появления, затухания и смены состояний для интерактивных элементов и страниц.

5. **Удобный возврат назад (Back Button).**
    *   **Суть:** Управлять поведением нативной кнопки "Назад" в Telegram (`BackButton`). Пользователь ожидает, что она будет логично возвращать его на предыдущий шаг внутри Mini App, а не закрывать приложение.
    *   **Действие:** Настроить `BackButton` для всех экранов, чтобы обеспечить интуитивную навигацию.
