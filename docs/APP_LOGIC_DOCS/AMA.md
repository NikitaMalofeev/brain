# Ask Me Anything (AMA) - Brain Programming

## Механика жизней в приложении

**Стартовое количество:** 3 жизни у каждого участника

**Как теряются жизни:**
- При каждой просрочке домашнего задания участник теряет 1 жизнь
- Даже если участник потом сдает просроченное дз, жизнь НЕ возвращается

**При 0 жизней:**
- Участник еще может продолжать обучение
- В UI жизни подсвечиваются ярко-красным цветом (предупреждение)
- Доступ к материалам сохраняется

**При нарушении дедлайна с 0 жизнями:**
- Участник автоматически считается "умершим"
- Остаются в доступе только материалы 1-го и 2-го уровней (ступеней)
- Новые материалы больше не открываются
- Сохраняется доступ только к тем материалам, которые уже успели открыться до "смерти"

**Техническая реализация:**
- Поле `lives_remaining` в таблице `users` отслеживает количество жизней
- При `lives_remaining = 0` - красная подсветка в UI
- Дополнительная логика блокировки доступа к новым материалам при превышении лимита
