# Функционал блоков материала

## Обзор

Добавлен новый тип блока `material` в уроки, который позволяет ссылаться на материалы из библиотеки и отображать их в виде кнопки с переходом к материалу.

## Архитектура

### База данных

**Новое поле в `lesson_blocks`:**
- `material_id` (UUID, FK → materials.id) - ссылка на материал из библиотеки
- Обновлен CHECK constraint для поддержки типа `'material'`

**Миграция:** `20250102000000_add_material_id_to_lesson_blocks.sql`

### Типы

**Обновлен `BlockType`:**
```typescript
export type BlockType =
  | 'text'      // Текстовый блок
  | 'video'     // Видео (Kinescope)
  | 'audio'     // Аудио (CloudFlare R2)
  | 'image'     // Изображение
  | 'pdf'       // PDF файл
  | 'material'; // Ссылка на материал из библиотеки
```

**Обновлен `LessonBlock`:**
```typescript
export interface LessonBlock extends TimestampFields {
  // ... существующие поля
  material_id?: string; // Для material-блоков - ссылка на материал
}
```

## Компоненты

### MaterialBlock

**Файл:** `src/components/LessonContent/MaterialBlock.tsx`

**Функциональность:**
- Загружает данные материала по `material_id`
- Отображает кнопку с обложкой, названием и описанием материала
- При клике переходит на страницу материала (`/material/:id`)
- Поддерживает все типы материалов (video, audio, article, link, file)

**Дизайн:**
- Карточка с обложкой материала (16x16)
- Название и тип материала
- Описание (если есть)
- Иконка перехода (стрелка вправо)
- Hover эффекты

## Использование

### Создание блока материала в админке

1. Перейти к управлению блоками урока
2. Нажать "Добавить блок"
3. Выбрать тип "📚 Материал"
4. Выбрать материал из выпадающего списка
5. Добавить описание (опционально)
6. Сохранить

### Отображение на фронтенде

- Блок отображается как кнопка с обложкой материала
- При клике пользователь переходит на страницу материала
- Поддерживается описание блока под кнопкой

## Преимущества

1. **Переиспользование контента** - один материал можно использовать в разных уроках
2. **Централизованное управление** - материалы управляются отдельно от уроков
3. **Гибкость** - материал может содержать любой тип контента (видео, аудио, статьи)
4. **Удобная навигация** - кнопка с визуальным представлением материала

## Ограничения

- Material блок может ссылаться только на существующие материалы
- При удалении материала все ссылки на него становятся недействительными
- Нет поддержки вложенных material блоков (material внутри material)
