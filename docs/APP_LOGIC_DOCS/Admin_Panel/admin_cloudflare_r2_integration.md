# Интеграция CloudFlare R2 в админке Brain Programming

> ⚙️ **См. также:** [Настройка CloudFlare R2](./cloudflare_r2_setup.md) - как настроить инфраструктуру

## Обзор

В админке реализована полная интеграция с CloudFlare R2 Object Storage для загрузки и управления медиафайлами. Интеграция позволяет админам загружать файлы напрямую из интерфейса при создании блоков уроков и дополнительных материалов.

## Основные возможности

### 🎯 Автоматическая загрузка файлов
- **Drag & Drop** - перетаскивание файлов в зону загрузки
- **Клик для выбора** - стандартный выбор файлов через диалог
- **Автоматическое определение типа** - файлы размещаются в правильные папки
- **Превью загруженных файлов** - предварительный просмотр
- **Альтернативный ввод URL** - возможность ручного ввода URL файлов

### 📁 Организация файлов по типам
| Тип блока | Папка в R2 | Поддерживаемые форматы |
|-----------|------------|----------------------|
| `audio` | `audio/` | mp3, wav, ogg, aac, flac, **m4a** |
| `image` | `images/` | jpg, png, gif, webp, svg, bmp |
| `pdf` | `documents/` | pdf |
| `material_covers` | `images/` | jpg, png, webp |
| `material_blocks` | см. выше по типу | все вышеперечисленные |

### 🎬 Специальная обработка видео
Видео блоки используют внешние платформы (Kinescope, YouTube, Vimeo), поэтому для них загрузка файлов не предусмотрена - только ввод URL.

### 🆕 Новые возможности (РЕАЛИЗОВАНО)
- ✅ **Поддержка m4a файлов** - добавлена поддержка m4a формата для аудио
- ✅ **Загрузка обложек материалов** - отдельная папка для обложек дополнительных материалов
- ✅ **Унифицированная система** - одинаковая логика для уроков и материалов
- ✅ **Валидация при сохранении** - JavaScript валидация перед отправкой файлов

## Компоненты интеграции

### FileUploader компонент
**Местоположение:** `src/components/FileUploader/FileUploader.tsx`

**Основные props:**
- `onUploadComplete` - callback при успешной загрузке
- `onUploadError` - callback при ошибке загрузки  
- `acceptedTypes` - MIME типы принимаемых файлов
- `filePrefix` - принудительное указание папки в R2
- `currentFileUrl` - URL текущего файла для превью
- `disabled` - блокировка загрузки

**Обновленные возможности:**
- Drag & drop интерфейс с улучшенной визуализацией
- Превью для изображений, аудио (включая m4a) и PDF
- Обработка ошибок загрузки с детальными сообщениями
- Автоматическая генерация уникальных имен файлов
- Поддержка альтернативного ввода URL

### Интеграция в BlocksManager
**Местоположение:** `src/pages/AdminPage/AdminPage.tsx` (компонент BlocksManager)

### Интеграция в MaterialsManager (НОВОЕ)
**Местоположение:** `src/pages/AdminPage/components/MaterialsManager/MaterialsManager.tsx`

**Как работает:**
1. При выборе типа блока `audio`, `image` или `pdf` отображается FileUploader
2. При загрузке файла автоматически заполняется поле `content_url`
3. Сохраняется полный публичный URL для доступа к файлу
4. Остается возможность ручного ввода URL (для файлов загруженных другим способом)
5. **НОВОЕ:** Поддержка m4a файлов в списке acceptedTypes
6. **НОВОЕ:** Загрузка обложек материалов в отдельную папку

## Пример использования

### 1. Создание аудио блока материала (ОБНОВЛЕНО)
```
1. Админка → Материалы → [Материал] → Блоки
2. "Добавить блок" → Тип: "🔊 Аудио"  
3. Перетащить .mp3/.m4a файл в зону загрузки
4. Файл автоматически загрузится в папку materials/blocks/
5. URL заполнится автоматически
6. Альтернативно: ввести URL вручную
7. Опционально добавить описание
8. Сохранить блок
```

### 2. Загрузка обложки материала (НОВОЕ)
```
1. Материалы → [Создать материал] или [Редактировать материал]
2. Секция "Обложка материала"
3. Загрузить .jpg/.png файл через FileUploader
4. Увидеть превью обложки
5. Файл загрузится в папку images/
6. Сохранить материал
```

## Безопасность и ограничения

### ✅ Реализовано
- **Проверка прав доступа** - только админы и кураторы могут загружать файлы
- **Валидация типов файлов** - на уровне браузера и сервера R2
- **Уникальные имена файлов** - предотвращение конфликтов имен
- **Обработка ошибок** - показ понятных сообщений пользователю
- **JavaScript валидация** - проверка данных перед отправкой
- **Поддержка m4a формата** - расширенная поддержка аудио файлов

### ⚠️ Ограничения
- **Размер файлов** - ограничен настройками CloudFlare R2 (обычно до 5GB)
- **Публичный доступ** - все загруженные файлы доступны по прямой ссылке
- **Нет автоматического удаления** - старые файлы нужно удалять вручную из R2 консоли

## Требуемые переменные окружения

```env
# CloudFlare R2 Storage (обязательны для работы)
VITE_CLOUDFLARE_R2_ACCOUNT_ID=your_account_id
VITE_CLOUDFLARE_R2_ACCESS_KEY_ID=your_access_key_id
VITE_CLOUDFLARE_R2_SECRET_ACCESS_KEY=your_secret_key
VITE_CLOUDFLARE_R2_PUBLIC_URL=https://pub-77b01fa701e84f019ef02376a7fb67f1.r2.dev
```

⚠️ **Важно:** Переменные должны иметь префикс `VITE_` для работы в браузере!

## Возможные проблемы и решения

### Проблема: "CloudFlare R2 credentials are not configured"
**Решение:** Проверьте наличие всех переменных окружения в .env файле

### Проблема: m4a файлы не загружаются
**Решение:** 
1. Убедитесь что m4a добавлен в acceptedTypes компонента FileUploader
2. Проверьте MIME тип файла (должен быть audio/mp4 или audio/x-m4a)

### Проблема: Файл не загружается
**Решение:** 
1. Проверьте права API токена в CloudFlare
2. Убедитесь что бакет `brain-programming` существует
3. Проверьте консоль браузера на наличие CORS ошибок
