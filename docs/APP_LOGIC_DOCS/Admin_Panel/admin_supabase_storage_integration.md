# Интеграция Supabase Storage в админке Brain Programming

> ⚙️ **См. также:** [Настройка Supabase Storage](./../../../supabase_setup.md) - как настроить инфраструктуру (файл будет создан позже)

## Обзор

В админке реализована полная интеграция с **Supabase Storage** для загрузки и управления медиафайлами. Интеграция позволяет админам загружать файлы напрямую из интерфейса при создании блоков уроков и дополнительных материалов. Это полностью заменяет предыдущую систему на базе Cloudflare R2.

## Основные возможности

### 🎯 Автоматическая загрузка файлов
- **Drag & Drop** - перетаскивание файлов в зону загрузки
- **Клик для выбора** - стандартный выбор файлов через диалог
- **Автоматическое определение типа** - файлы размещаются в правильные папки (`images/`, `audio/`, `documents/`) внутри бакета `media`.
- **Превью загруженных файлов** - предварительный просмотр
- **Альтернативный ввод URL** - возможность ручного ввода URL файлов (например, для видео с Kinescope)

### 📁 Организация файлов по типам
| Тип блока | Папка в Supabase Storage (Бакет: `media`) | Поддерживаемые форматы |
|-----------|--------------------------------------------|--------------------------|
| `audio` | `audio/` | mp3, wav, ogg, aac, flac, **m4a** |
| `image` | `images/` | jpg, png, gif, webp, svg, bmp |
| `pdf` | `documents/` | pdf |
| `material_covers` | `images/` | jpg, png, webp |
| `lesson_covers` | `images/` | jpg, png, webp |
| `curator_avatars` | `images/` | jpg, png, webp |

### 🎬 Специальная обработка видео
Видео блоки используют внешние платформы (Kinescope), поэтому для них загрузка файлов не предусмотрена - только ввод URL.

### 🆕 Новые возможности (РЕАЛИЗОВАНО)
- ✅ **Поддержка m4a файлов** - добавлена поддержка m4a формата для аудио
- ✅ **Загрузка обложек материалов и уроков** - унифицированная система для всех обложек
- ✅ **Унифицированная система** - одинаковая логика для уроков и материалов
- ✅ **Валидация при сохранении** - JavaScript валидация перед отправкой файлов

## Компоненты интеграции

### FileUploader компонент
**Местоположение:** `src/components/FileUploader/FileUploader.tsx`

**Основные props:**
- `onUploadComplete` - callback при успешной загрузке
- `onUploadError` - callback при ошибке загрузки  
- `acceptedTypes` - MIME типы принимаемых файлов
- `filePrefix` - принудительное указание папки в бакете `media` (например, `FILE_PREFIXES.AUDIO`)
- `currentFileUrl` - URL текущего файла для превью
- `disabled` - блокировка загрузки

### Использование в админ-панели
- **`BlocksManager`**: `src/pages/AdminPage/components/BlocksManager/BlocksManager.tsx`
- **`MaterialsManager`**: `src/pages/AdminPage/components/MaterialsManager/MaterialsManager.tsx`
- **`LessonsManager`**: `src/pages/AdminPage/components/LessonsManager.tsx`
- **`CuratorsManager`**: `src/pages/AdminPage/components/CuratorsManager/CuratorAvatarModal.tsx`

**Как работает:**
1. При выборе типа блока (`audio`, `image`, `pdf`) или действия (загрузка обложки/аватара) отображается `FileUploader`.
2. При загрузке файла, он отправляется в соответствующую папку бакета `media` в Supabase.
3. В базу данных сохраняется **относительный путь** к файлу (например, `images/my-cover.jpg`).
4. Полный публичный URL формируется на лету с помощью `supabase.storage.from('media').getPublicUrl(path)`.

## Структура сгенерированных URL

Все файлы становятся доступны по публичным URL нашего инстанса Supabase:

```
https://[YOUR_PROJECT_REF].supabase.co/storage/v1/object/public/media/[папка]/[уникальное_имя]

Примеры:
• https://bzbpwmzhywaqwsjthwid.supabase.co/storage/v1/object/public/media/audio/meditation_intro_1685123456.mp3
• https://bzbpwmzhywaqwsjthwid.supabase.co/storage/v1/object/public/media/images/lesson_cover_1685123456.jpg
```

## Безопасность и ограничения

### ✅ Реализовано
- **Проверка прав доступа (RLS)** - только аутентифицированные админы могут загружать файлы, благодаря JWT-токену, который передается при каждом запросе.
- **Валидация типов файлов** - на уровне браузера и политик бакета.
- **Уникальные имена файлов** - для предотвращения конфликтов.
- **Обработка ошибок** - показ понятных сообщений пользователю при сбоях загрузки.
- **Каскадное удаление** - при удалении сущностей (блоков, уроков) связанные файлы также удаляются из Storage.

### ⚠️ Ограничения
- **Размер файлов** - ограничен настройками Supabase (зависит от тарифного плана).
- **Публичный доступ** - все загруженные файлы в бакет `media` доступны по прямой ссылке.

## Требуемые переменные окружения

Для работы со Storage на клиенте достаточно основных переменных Supabase.

```env
# Supabase
VITE_SUPABASE_URL=https://bzbpwmzhywaqwsjthwid.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

⚠️ **Важно:** Переменные должны иметь префикс `VITE_` для работы в браузере!
