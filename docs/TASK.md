**Основной функционал:**
- Кнопка "Изменить решение" в детальном просмотре проверенных сабмитов
- Форма для изменения статуса с обязательным полем "Причина изменения"  
- **НОВОЕ:** Корректировка количества баллов для принятых заданий (approved → approved)
- Автоматический пересчет баллов пользователя при изменении решения
- Система прав: кураторы могут изменять только свои решения (включая баллы), админы - любые
- Упрощенная логика комментариев: новый заменяет старый или остается старый

**План реализации:**
1. 🟢 Обновить SubmissionDetail.tsx - добавить UI для изменения решений
   - ✅ Показывать кнопку "Изменить решение" для проверенных сабмитов
   - ✅ Добавить форму редактирования с валидацией прав доступа
   - ✅ Реализовать логику пересчета баллов (включая корректировку)
   - ✅ Поддержка сценария approved → approved с новыми баллами
   - ✅ Упрощенная логика комментариев (заменять или оставлять)
   - ✅ Предупреждения о пересчете и уведомления
2. 🟢 Получение ID текущего пользователя из Supabase auth
3. 🟢 Исправить проблему с UUID 'admin_password_user' - создана система веб-авторизации
4. 🟢 Протестировать функционал в браузере
   - ✅ Исправлена проблема с отображением быстрых действий при изменении решения
   - ✅ Быстрые действия теперь показываются только при первичной проверке
   - ✅ Добавлено сохранение сессии авторизации в localStorage
   - ✅ Пользователя больше не разлогинивает при обновлении страницы
5. 🔴 Добавить SQL функцию для логирования изменений (опционально)
6. ✅ Обновить документацию flow

**Логика пересчета баллов (реализовано):**
- При approved → rejected: `users.total_points -= old_points_awarded`
- При rejected → approved: `users.total_points += new_points_awarded`  
- При approved → approved: `users.total_points += (new_points - old_points)` **← НОВОЕ!**

**Система прав доступа (реализовано):**
- **Кураторы:** полный функционал для своих сабмитов (включая корректировку баллов)
- **Админы:** полный функционал для всех сабмитов
- Кнопка "Изменить решение" показывается только при наличии прав

**ТЕХНИЧЕСКОЕ ИСПРАВЛЕНИЕ:**
- ✅ Создана система веб-авторизации с логином/паролем для админов и кураторов
- ✅ Расширена таблица `users` полями `web_login`, `web_password_hash`, `web_last_login`
- ✅ Создана функция `authenticate_web_user()` для проверки авторизации

### 🟡 **[UX]** Отображение результатов проверки заданий на странице урока - В процессе 🔄

**Дата начала:** 2025-01-30  
**Цель:** Добавить отображение результатов проверки заданий (approved/rejected) на странице урока + возможность пересдачи отклоненных заданий

**Проблема:** 
Пользователи не видят результаты проверки своих заданий. После сдачи показывается только "✅ Задание сдано на проверку", но нет информации об approved/rejected, комментариях куратора и начисленных баллах.

**Основной функционал:**
- **Умный блок результатов** с разными состояниями по статусу задания:
  - `submitted/pending_review` → "⏳ Задание на проверке"  
  - `approved` → "✅ Задание принято! +X баллов" + комментарий куратора
  - `rejected` → "❌ Задание требует доработки" + комментарий + кнопка пересдачи
- **Пересдача отклоненных заданий** через ту же FixedSubmissionForm
- **Отображение feedback** от кураторов и информации о проверке
- **Предзаполнение формы** при пересдаче предыдущим ответом

**План реализации:**
1. 🟢 Создать функцию `renderSubmissionResult()` в LessonPage.tsx
2. 🟢 Добавить загрузку данных куратора в submission запрос  
3. 🟢 Реализовать логику пересдачи rejected заданий
4. 🟢 Обновить FixedSubmissionForm для поддержки предзаполнения
5. 🟢 Исправить проблему с автоматическим закрытием формы при пересдаче
6. 🔴 Протестировать все состояния: pending → approved → rejected → пересдача
7. 🟢 Обновить документацию lesson_view_flow.md
