**SQL схема:**
```sql
-- Основной запрос списка сабмитов
SELECT s.*, u.first_name, u.last_name, u.photo_url, 
       l.name as lesson_name, cs.name as stage_name,
       reviewer.first_name as reviewer_name
FROM submissions s
JOIN users u ON s.user_id = u.id  
JOIN lessons l ON s.lesson_id = l.id
JOIN course_stages cs ON l.stage_id = cs.id
LEFT JOIN users reviewer ON s.reviewed_by_curator_id = reviewer.id
WHERE s.status IN ('submitted', 'pending_review')
ORDER BY s.submitted_at DESC;

-- Обновление результата проверки
UPDATE submissions 
SET status = $1, points_awarded = $2, feedback_text = $3,
    reviewed_by_curator_id = $4, reviewed_at = NOW()
WHERE id = $5;

-- Начисление баллов пользователю (при approved)
UPDATE users 
SET total_points = total_points + $1 
WHERE id = $2;
```

**Логика пересчета баллов (реализовано):**
- При approved → rejected: `users.total_points -= old_points_awarded`
- При rejected → approved: `users.total_points += new_points_awarded`  
- При approved → approved: `users.total_points += (new_points - old_points)` **← НОВОЕ!**

**Система прав доступа (реализовано):**
- **Кураторы:** полный функционал для своих сабмитов (включая корректировку баллов)
- **Админы:** полный функционал для всех сабмитов
- Кнопка "Изменить решение" показывается только при наличии прав
