### 🟡 **[Фича]** Реализация фичи «Ученики и Кураторы» (на основе students_curators_feature.md)
*Дата начала: 04.06.2025*

**Описание:** Добавить в админ-панель функционал для управления учениками, кураторами, их взаимосвязями и просмотра детальной статистики по прогрессу учеников, включая просмотры дополнительных материалов.

**Подзадачи:**

**I. Бэкенд (Supabase & Хуки):**
  - 🟢 **SQL & Schema:**
    - 🟢 Подготовить SQL-скрипт для создания таблицы `user_curator` (Применен в БД).
    - 🟢 Убедиться, что поле `web_last_login` добавлено в таблицу `users` и обновляется корректно при веб-входе (Поле уже существовало).
    - 🟢 SQL функции `get_students_list` и `get_curators_list` созданы и готовы к использованию через .rpc() вызовы.
    - 🟢 **ИСПРАВЛЕНО:** Функция `get_students_list` работает корректно после исправления типов данных.
  - 🟢 **React Hooks для Таба «Ученики»:**
    - 🟢 `useStudentsAdmin`: Хук для получения списка учеников с сортировкой (по баллам, дате регистрации, последнему входу) и пагинацией. Использует SQL функцию `get_students_list`.
    - 🟢 `useStudentDetails`: Хук для получения детальной информации по ученику (основная инфо, курсы, прогресс по урокам и материалам).
    - 🟢 `useStudentActions`: Хук для действий с учеником:
        - Сброс прогресса конкретного урока для ученика
        - Отметить дополнительный материал как просмотренный/завершенный
        - Сбросить отметку просмотра дополнительного материала
  - 🟢 **React Hooks для Таба «Кураторы»:**
    - 🟢 `useCuratorsAdmin`: Хук для получения списка кураторов с пагинацией. Использует SQL функцию `get_curators_list`.
    - 🟢 `useCuratorDetails`: Хук для получения детальной информации по куратору и списка его учеников с прогрессом.
    - 🟢 `useCuratorActions`: Хук для управления связями куратор-ученик:
        - Назначение ученика куратору (создание записи в `user_curator`)
        - Отвязка ученика от куратора (удаление записи из `user_curator`)
  - 🔴 **RLS (Row Level Security):**
    - 🟢 Настроить политики безопасности для таблицы `user_curator` (Применены в SQL-скрипте).
    - 🔴 Проверить и при необходимости обновить RLS для существующих таблиц (`users`, `lesson_progress`, `user_material_views`) с учетом новых сценариев доступа (например, куратор может видеть прогресс своих учеников).
    - 🔴 Обеспечить, чтобы только администраторы и соответствующие кураторы могли выполнять операции по назначению/отвязке и просмотру данных.
