**Дата:** 26.06.2025

**ПРОБЛЕМА:** Существующая кастомная система входа для админов (`authenticate_web_user`) не создает стандартную сессию Supabase (JWT), из-за чего невозможно проверить права админа на уровне политик RLS в базе данных.

**РЕШЕНИЕ:** Модернизировать систему входа, чтобы она генерировала стандартный JWT-токен для админа, что позволит использовать RLS-политики для безопасного управления файлами.
