## Задачи на текущий момент

### Исправление проблем с Realtime обновлениями 🟢 Выполнено

**Описание проблемы:** 
В приложении наблюдалось зацикливание обновлений данных пользователя и списка всех пользователей через Supabase Realtime. Это вызывало постоянные мерцания UI, высокую нагрузку на сеть и многочисленные повторные рендеры компонентов.

**Решение:**
1. Внедрен механизм debounce для обновлений из Realtime в `useSupabaseUser` хуке:
   - Добавлено отслеживание последнего обновления по времени и ID
   - Игнорирование повторных обновлений с тем же ID или в течение 200 мс
   - Использование таймера для откладывания обновлений состояния на 300 мс

2. Оптимизированы запросы в `IndexPage`:
   - Переписана функция `fetchAllUsers` с использованием useCallback и защитой от частых вызовов
   - Добавлен механизм throttling для обновлений из Realtime (минимум 2 секунды между обновлениями)
   - Правильная очистка таймеров при размонтировании компонента

**Результат:**
- Значительно снижено количество обновлений состояния и запросов к API
- Устранено мерцание UI элементов
- Улучшена отзывчивость интерфейса
- Снижен сетевой трафик и нагрузка на сервер
