## 🎯 ПРЕДВАРИТЕЛЬНЫЕ ТРЕБОВАНИЯ

### Что должно быть в базе данных:

- ✅ Хотя бы один курс (`courses`)
- ✅ Хотя бы одна ступень (`course_stages`)
- ✅ Хотя бы один урок (`lessons`)
- ✅ Хотя бы один тариф (`tariffs`)

### Типы пользователей для тестирования:

Для полноценного тестирования нужны **3 типа пользователей**:

1. **Гость** - без активного тарифа
2. **Ученик** - с активным тарифом, записан на поток
3. **Куратор** - с ролью `curator`, назначены ученики

## 👥 СОЗДАНИЕ ТЕСТОВЫХ ПОЛЬЗОВАТЕЛЕЙ

### Вариант A: Через Telegram Bot (рекомендуется)

1. Откройте ваш Telegram бот
2. Запустите его командой `/start`
3. Зарегистрируйтесь как 3 разных пользователя:
   - **Гость** - не покупайте тариф
   - **Ученик** - купите тариф
   - **Куратор** - купите тариф

### Вариант B: Через SQL (быстрый способ)

**Важно:** Замените UUID на реальные ID пользователей из вашей таблицы `users`.

Сначала найдите ID пользователей:

```sql
-- Найти ID пользователей
SELECT id, first_name, telegram_id, role FROM users LIMIT 10;
```

Затем выполните этот скрипт:

```sql
-- =================================
-- БЫСТРАЯ НАСТРОЙКА ТЕСТОВЫХ ПОЛЬЗОВАТЕЛЕЙ
-- =================================

DO $$
DECLARE
  -- ❗ ЗАМЕНИТЕ ЭТИ UUID НА РЕАЛЬНЫЕ ID ПОЛЬЗОВАТЕЛЕЙ ИЗ ВАШЕЙ БД
  v_guest_id UUID := '00000000-0000-0000-0000-000000000001'; -- ID гостя
  v_student_id UUID := '00000000-0000-0000-0000-000000000002'; -- ID ученика
  v_curator_id UUID := '00000000-0000-0000-0000-000000000003'; -- ID куратора

  v_stream_id UUID := 'b1111111-1111-1111-1111-111111111111';
  v_tariff_id UUID;
BEGIN
  -- Получить первый тариф
  SELECT id INTO v_tariff_id FROM tariffs LIMIT 1;

  IF v_tariff_id IS NULL THEN
    RAISE EXCEPTION 'Нет тарифов в базе. Создайте хотя бы один тариф.';
  END IF;

  -- ========================
  -- 1. НАСТРОЙКА ГОСТЯ
  -- ========================
  -- Убедимся что у него НЕТ активного тарифа
  DELETE FROM user_tariff_purchases WHERE user_id = v_guest_id;

  RAISE NOTICE '✅ Гость настроен (без тарифа)';

  -- ========================
  -- 2. НАСТРОЙКА УЧЕНИКА
  -- ========================

  -- Выдать активный тариф
  INSERT INTO user_tariff_purchases (
    user_id,
    tariff_id,
    is_active,
    expiration_date,
    purchase_date
  ) VALUES (
    v_student_id,
    v_tariff_id,
    TRUE,
    NOW() + INTERVAL '180 days',
    NOW()
  )
  ON CONFLICT (user_id, tariff_id) DO UPDATE SET
    is_active = TRUE,
    expiration_date = NOW() + INTERVAL '180 days';

  -- Записать на поток
  INSERT INTO user_stream_enrollments (user_id, stream_id)
  VALUES (v_student_id, v_stream_id)
  ON CONFLICT (user_id, stream_id) DO NOTHING;

  RAISE NOTICE '✅ Ученик настроен (с тарифом + записан на поток)';

  -- ========================
  -- 3. НАСТРОЙКА КУРАТОРА
  -- ========================

  -- Выдать тариф куратору
  INSERT INTO user_tariff_purchases (
    user_id,
    tariff_id,
    is_active,
    expiration_date,
    purchase_date
  ) VALUES (
    v_curator_id,
    v_tariff_id,
    TRUE,
    NOW() + INTERVAL '180 days',
    NOW()
  )
  ON CONFLICT (user_id, tariff_id) DO UPDATE SET
    is_active = TRUE,
    expiration_date = NOW() + INTERVAL '180 days';

  -- Установить роль куратора
  UPDATE users SET role = 'curator' WHERE id = v_curator_id;

  -- Назначить куратору учеников
  INSERT INTO user_curator (curator_id, student_id)
  VALUES (v_curator_id, v_student_id)
  ON CONFLICT DO NOTHING;

  RAISE NOTICE '✅ Куратор настроен (с ролью curator + назначены ученики)';

  -- ========================
  -- 4. ТЕСТОВЫЕ ДАННЫЕ
  -- ========================

  -- Выдать технику "Императрица" ученику для тестирования
  PERFORM grant_technique_to_user(v_student_id, 'a1111111-1111-1111-1111-111111111111');

  RAISE NOTICE '✅ Ученику выдана техника "Императрица"';

  -- ========================
  -- ИТОГ
  -- ========================
  RAISE NOTICE '';
  RAISE NOTICE '====================================';
  RAISE NOTICE 'ТЕСТОВЫЕ ПОЛЬЗОВАТЕЛИ НАСТРОЕНЫ';
  RAISE NOTICE '====================================';
  RAISE NOTICE '';
  RAISE NOTICE 'Гость ID: %', v_guest_id;
  RAISE NOTICE 'Ученик ID: %', v_student_id;
  RAISE NOTICE 'Куратор ID: %', v_curator_id;
  RAISE NOTICE '';
  RAISE NOTICE 'Теперь можно начинать тестирование!';
  RAISE NOTICE '';

END $$;
```

## 🐛 TROUBLESHOOTING

### Проблема: Техники не отображаются

**Решение:**
```sql
-- Проверить что техники созданы
SELECT * FROM techniques;

-- Если пусто - применить seed-данные заново
-- Выполните миграцию 20251117200000_seed_test_data.sql
```

---

### Проблема: События календаря не показываются

**Решение:**
```sql
-- Проверить что пользователь записан на поток
SELECT * FROM user_stream_enrollments WHERE user_id = 'YOUR_USER_ID';

-- Если нет - добавить
INSERT INTO user_stream_enrollments (user_id, stream_id)
VALUES ('YOUR_USER_ID', 'b1111111-1111-1111-1111-111111111111');
```

---

### Проблема: Домашние задания не загружаются

**Решение:**
```sql
-- Проверить что assignments созданы
SELECT * FROM assignments WHERE lesson_id = 1;

-- Если нет - применить seed-данные заново
```

---

### Проблема: Гость видит весь контент

**Решение:**
```sql
-- Проверить что у пользователя нет активного тарифа
SELECT * FROM user_tariff_purchases
WHERE user_id = 'YOUR_USER_ID' AND is_active = TRUE;

-- Если есть - деактивировать
UPDATE user_tariff_purchases
SET is_active = FALSE
WHERE user_id = 'YOUR_USER_ID';
```

---

### Проблема: Миграции не применяются

**Решение:**
1. Проверьте логи в Supabase Dashboard
2. Убедитесь что миграции применяются в правильном порядке
3. Попробуйте применить каждую миграцию отдельно через SQL Editor
4. Проверьте что нет конфликтов с существующими таблицами

---

### Проблема: Edge Function не отправляет уведомления

**Решение:**
1. Проверить логи в Supabase Dashboard → Edge Functions → Logs
2. Проверить что `TELEGRAM_BOT_TOKEN` установлен:
   ```bash
   supabase secrets list --project-ref YOUR_PROJECT_REF
   ```
3. Проверить что у пользователя есть `telegram_id`:
   ```sql
   SELECT id, telegram_id FROM users WHERE id = 'YOUR_USER_ID';
   ```
4. Проверить что событие на завтра существует:
   ```sql
   SELECT * FROM calendar_events WHERE event_date = CURRENT_DATE + INTERVAL '1 day';
   ```
