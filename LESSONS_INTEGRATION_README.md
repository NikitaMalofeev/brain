# Интеграция системы уроков в модули потоков

## Обзор изменений

Система уроков (course_stages и lessons) теперь интегрирована в архитектуру модулей потоков:

**Было**: Курс → Ступени → Уроки
**Стало**: Курс → Поток → Тариф → Модуль → **(Техники + Ступени с уроками)**

## Структура базы данных

### 1. Таблица `course_stages`
Добавлено поле:
- `stream_module_id` (UUID) - связь со stream_modules, указывает к какому модулю потока относится ступень

### 2. Таблица `lessons`
Добавлено поле:
- `stream_id` (UUID) - связь со streams, необходима для корректного копирования при дублировании потока

## Компоненты

### 1. ModuleContentManager
**Файл**: `src/pages/AdminPage/components/StreamsManager/ModuleContentManager.tsx`

Главный компонент-обертка с переключателем (Segmented от Ant Design):
- **Техники** - отображает `ModuleTechniquesManager`
- **Уроки** - отображает `ModuleLessonsManager`

### 2. ModuleLessonsManager
**Файл**: `src/pages/AdminPage/components/StreamsManager/ModuleLessonsManager.tsx`

Компонент для управления ступенями и уроками внутри модуля:
- Создание/редактирование/удаление ступеней
- Создание/редактирование/удаление уроков в ступенях
- Иерархическое отображение: Ступень → Уроки
- Использует Ant Design (Collapse, Modal, Form)

### 3. Обновлен StreamEditor
**Файл**: `src/pages/AdminPage/components/StreamsManager/StreamEditor.tsx`

Заменен `ModuleTechniquesManager` на `ModuleContentManager` для отображения переключателя.

## Хуки

### useModuleStages
**Файл**: `src/lib/supabase/hooks/useModuleStages.ts`

Хуки для работы с ступенями и уроками в модулях:
- `useModuleStages(streamModuleId)` - получить все ступени модуля с уроками
- `useCreateStageInModule()` - создать ступень в модуле
- `useUpdateStage()` - обновить ступень
- `useDeleteStage()` - удалить ступень
- `useCreateLessonInStage()` - создать урок в ступени
- `useUpdateLesson()` - обновить урок
- `useDeleteLesson()` - удалить урок

## Копирование потоков

### Обновлена функция copy_stream
**Файл**: `supabase/migrations/20251126110000_add_lessons_to_copy_stream.sql`

При копировании потока автоматически копируются:
1. Модули потока
2. **Ступени модулей** (course_stages) - с привязкой к новым модулям
3. **Уроки ступеней** (lessons) - с привязкой к новым ступеням
4. Техники модулей
5. События календаря
6. Настройки тарифов

**Важно**: Даты уроков (`open_at`, `deadline_at`) автоматически сдвигаются на разницу между старой и новой датой начала потока.

## Миграции базы данных

### 1. `20251126100000_link_stages_to_modules.sql`
- Добавляет `stream_module_id` в `course_stages`
- Добавляет `stream_id` в `lessons`
- Создает индексы для быстрого поиска

### 2. `20251126110000_add_lessons_to_copy_stream.sql`
- Обновляет функцию `copy_stream()` с поддержкой копирования ступеней и уроков
- Копирует маппинг старых ID на новые
- Сдвигает даты уроков автоматически

## Использование в админке

1. Зайти в **Потоки** → Выбрать поток → **Редактировать**
2. Раскрыть модуль
3. Увидеть переключатель **Техники / Уроки**
4. Переключиться на **Уроки**
5. Создать ступень (например, "Неделя 1")
6. Внутри ступени создать уроки (например, "День 1", "День 2")
7. При копировании потока все ступени и уроки автоматически скопируются

## Проверка работы

### Создание ступени и урока
1. Откройте поток в редакторе
2. Раскройте модуль
3. Переключитесь на "Уроки"
4. Создайте ступень
5. Добавьте урок в ступень

### Копирование потока с уроками
1. Создайте поток с модулями, ступенями и уроками
2. Скопируйте поток через кнопку "Копировать"
3. Укажите новую дату начала
4. Проверьте что в новом потоке есть все ступени и уроки
5. Проверьте что даты уроков сдвинуты корректно

## Логика работы

```
Курс
└── Поток
    ├── Модуль 1
    │   ├── Техники (вкладка)
    │   │   ├── Техника A (день 1)
    │   │   └── Техника B (день 3)
    │   └── Уроки (вкладка)
    │       ├── Ступень "Неделя 1"
    │       │   ├── Урок "День 1"
    │       │   ├── Урок "День 2"
    │       │   └── Урок "День 3"
    │       └── Ступень "Неделя 2"
    │           └── Урок "День 1"
    └── Модуль 2
        └── ...
```

## Преимущества новой архитектуры

1. **Единая структура**: Техники и уроки находятся в одном месте - в модулях
2. **Автоматическое копирование**: При дублировании потока копируются все данные
3. **Гибкость**: Можно использовать и техники, и уроки одновременно
4. **Масштабируемость**: Легко добавлять новые типы контента в модули
